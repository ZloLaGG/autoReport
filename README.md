# Автоматизация отчёта по продажам

## Задача

Сократить ручную подготовку отчёта по розничным продажам: загружать исходные данные, рассчитывать ключевые показатели и сохранять результаты в удобных для анализа форматах.

## Решение

Python-скрипт автоматически выполняет весь путь от Excel-файла до интерактивного отчёта:

1. Загружает `dataset/online_retail_II.xlsx` с помощью pandas.
2. Преобразует даты и рассчитывает выручку по строкам продаж (`Quantity × Price`).
3. Группирует данные по месяцам и товарам, формирует топ-10 товаров по выручке и количеству.
4. Сохраняет четыре набора результатов в SQLite через `DataFrame.to_sql`.
5. Создаёт Excel-книгу с четырьмя листами.
6. Показывает метрики, таблицы и фильтр по месяцам в Streamlit.

Расчёт отчёта кэшируется средствами Streamlit, чтобы не перечитывать и не пересчитывать данные при каждом изменении фильтра.

## Результат

После запуска создаются:

- `database.db` — SQLite-база с таблицами `revenue_month`, `top_products`, `top_by_quantity` и `average_month_check`.
- `report.xlsx` — Excel-отчёт с листами «Выручка по месяцам», «Топ продаж», «Топ по количеству» и «Средний чек по месяцам».
- Dashboard с общей выручкой, средним значением по строкам продаж, количеством выбранных месяцев и таблицами с результатами.

> Примечание: поле `AverageCheck` в текущей версии — среднее значение суммы строки продажи по месяцу. Оно не рассчитывается как средняя сумма по номеру чека (`Invoice`).

## Запуск

Требуется Python 3.10 или новее. Из корневой папки проекта установите зависимости и запустите приложение:

```powershell
python -m pip install pandas openpyxl streamlit
python -m streamlit run automatic.py
```

Затем откройте адрес, который появится в терминале, обычно `http://localhost:8501`.

В VS Code приложение также можно запустить через конфигурацию **Streamlit: automatic.py** в панели Run and Debug.
